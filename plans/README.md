# plans/ —— 平面图底图

把官方平面图的图片文件放进这个目录，编辑器左侧「平面图与校准」的下拉框里就会列出来。

支持的格式：`.png` `.jpg` `.jpeg` `.webp` `.gif` `.avif` `.svg` `.bmp`

## 建议

- **文件名带楼层**，例如 `3f.png` `4f.png` `1f.png`，编辑器的下拉框按文件名排序，找起来快
- **一张图只放一层**。多层拼在一张图里的话，校准没法做（各层比例可能不同）
- **用真正的平面图，不要用效果图/轴测图**。透视图有透视变形，任何线性校准都不准
- **分辨率够用就行**。建议长边 2000~4000 px：太小看不清店铺边界，太大编辑器会卡
- 如果原图是 PDF，先转成 PNG（300 dpi 左右）

## 版权

官方平面图有版权。

- **这个目录已加进 `.gitignore`** —— 底图不会被提交，只留在你本机
- 最终产品里**不要出现原图**。正确做法是：以它为参考**自己重绘矢量数据**，成品只渲染你自己画的 GeoJSON（这是业内通行做法）
- 对外发布时注明数据来源，并说明是基于公开平面图的人工重绘

## 没图也能画

没有图片也可以直接画，只是没法照着描。此时你是凭卫星图/记忆/现场测量的坐标在空白画布上打点，比例靠「两点定比例」自己定。
